# 小红书内容校准工作流

这个文档定义 `cheat-on-content` 在小红书 / 数字产品账号中的使用方式。

## 核心目标

把每一篇小红书笔记从“凭感觉发布”变成“可预测、可复盘、可迭代”的内容实验。

它不负责替你追热点，不负责承诺爆款，也不鼓励刷量。它负责帮你回答一个更关键的问题：

> 我的发布前判断，是否随着样本积累变得更准确？

## 适用账号

### 1. HSK / 对外汉语资料账号

典型产品：

- HSK 3.0 汉字学习卡；
- 认读字 / 书写字字帖；
- 对外汉语 PPT；
- 商品详情页模板；
- 中文老师备课资料。

核心指标不是泛流量，而是：收藏、评论需求、私信、商品点击、成交信号。

### 2. 幼小衔接 / 拼音识字账号

典型产品：

- 拼音闪卡；
- 识字卡；
- 幼小衔接练习页；
- 亲子打印资料；
- IP 化教育素材。

核心指标是：家长焦虑命中、可打印感、孩子视觉吸引力、购买冲动。

### 3. 资料库 / 技能产品化账号

典型产品：

- 外贸资料库；
- 行业调研包；
- 小红书选题库；
- AI 工作流模板；
- 数字产品制作手册。

核心指标是：真实需求感、可复制性、节省时间感、购买理由清晰度。

## 五阶段闭环

### 阶段 1：选题入池

每个候选选题至少记录：

- 标题草案；
- 目标用户；
- 用户痛点；
- 承接产品；
- 内容形式；
- 预期动作；
- 参考对标。

不要把“我觉得有意思”当成选题理由。选题必须能说清楚：谁会因为这条内容采取什么动作。

### 阶段 2：发布前评分

使用 `starter-rubrics/xhs-digital-product.md` 评分。

评分必须包含：

- 各维度分数；
- 加权总分；
- 最大风险；
- 最强购买触发点；
- 是否建议发布。

### 阶段 3：盲预测

预测必须在发布前完成。预测段一旦写入，不允许回头改。

小红书数字产品账号建议预测：

- 阅读 / 观看区间；
- 点赞区间；
- 收藏区间；
- 评论区间；
- 分享区间；
- 商品点击 / 私信区间；
- 最可能出现的评论类型；
- 最可能失败的原因。

冷启动阶段不要假装精确。可以写区间，不要写伪精确数字。

### 阶段 4：发布登记

发布后记录：

- 发布时间；
- 链接；
- 标题；
- 封面版本；
- 是否挂商品；
- 挂载商品名；
- 是否投流；
- 是否同步到其他账号。

### 阶段 5：T+3d 复盘

发布 3 天后，记录真实数据。

小红书复盘建议字段：

| 字段 | 说明 |
|---|---|
| 展现 | 平台分发量 |
| 阅读 / 观看 | 实际打开或观看 |
| 点赞 | 情绪认可 |
| 收藏 | 资料价值 / 以后会用 |
| 评论 | 讨论和需求信号 |
| 分享 | 传播价值 |
| 商品点击 | 商业承接 |
| 私信 | 强需求 |
| 成交 / 加购 | 最终转化 |
| Top 评论 | 真实用户语言 |

复盘时重点回答：

1. 哪个判断准了？
2. 哪个判断错了？
3. 是封面问题、标题问题、内容问题，还是产品承接问题？
4. 这条内容吸引的是目标买家，还是泛流量？
5. rubric 哪个维度需要调权重？

## 小红书内容的特殊判断

### 高阅读不一定好

如果阅读很高，但没有收藏、评论、私信和商品点击，可能只是泛流量。

### 低阅读不一定差

如果阅读不高，但收藏率、私信率和商品点击率高，这条内容可能是高商业价值内容。

### 收藏比点赞更重要

对资料包账号来说，收藏通常比点赞更接近购买意图。

### 评论语言是产品需求库

评论里出现这些信号要重点记录：

- “有链接吗？”
- “怎么买？”
- “适合几年级吗？”
- “有没有英文版？”
- “可以打印吗？”
- “老师可以课堂用吗？”
- “能不能做某某版本？”

这些不是普通评论，是产品迭代线索。

## 推荐 cadence

冷启动前 15 篇：

- 每天 1–2 篇；
- 每篇都做发布前预测；
- 每 3 天复盘一次；
- 每 5 篇做一次小 bump。

稳定期：

- 每周复盘一次；
- 每 10–15 篇做一次 rubric bump；
- 每月清理一次候选池。

## 三个项目不要混用 rubric

建议分开维护：

```text
xhs-hsk-products/
xhs-kids-literacy/
xhs-productization-notes/
```

原因：这三类内容的用户心理、购买理由、数据指标都不同。混在一个 rubric 里，会导致评分系统越来越钝。
